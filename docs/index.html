NEON RIFT

Le jeu de tir stickman où tout est destructible.

Chaque balle, roquette et rayon laser creuse le décor en temps réel : le sable s'écoule, les structures s'effondrent, et vous construisez murs et planchers en plein duel. Duels 1v1, salons jusqu'à 8 joueurs, survie solo et co-op — directement dans le navigateur.

ARSENAL RIFT

Des armes qui tordent la réalité

Trois armes exclusives Neon Rift, plus les classiques du genre — pistolet, SMG, shotgun, roquette, railgun, lance-flammes, C4, sniper, AK-47 et constructeur.

🌀

BLINK DISC

Disque de phase : téléporte-toi à l'impact, ou en plein vol (clic droit / G / E) pour recharger ton double saut et libérer une onde de choc sans auto-dégâts.

🔺

PRISM RIFLE

Laser cristallin qui rebondit jusqu'à 3 fois sur les murs (+15 % de dégâts par ricochet), avec aperçu du premier rebond.

🕳️

VORTEX ORB

Orbe de matière noire : s'ancre en singularité gravitationnelle, soulève et aspire les ennemis avant d'imploser.

COMMENT JOUER

En jeu en 30 secondes

1

Ouvre le jeu

Un clic sur le lien, aucun téléchargement. Le serveur gratuit peut mettre ~20 secondes à se réveiller après une pause.

2

Choisis ton mode

1v1, groupe, survie solo ou co-op — puis la carte et l'arsenal qui te ressemblent.

3

Détruis & construis

Creuse le décor, pose des murs et des sols en plein duel, et reprends l'avantage.

OPEN SOURCE

Construit par la communauté

Zéro monétisation, 100 % fun. Forke le projet, propose tes idées, ou héberge ton propre serveur.

🍴

Fork & lance

Clone le repo, npm install, puis npm run dev : le jeu tourne en local sur localhost:3030.

🤝

Contribue

Nouvelles armes, cartes destructibles, modes ou effets néon : le guide CONTRIBUTING.md t'explique tout, pas à pas.

🚀

Héberge

Render, Docker, Fly.io, Railway ou VPS : le guide DEPLOY.md couvre l'hébergement gratuit, clé en main.

git clone https://github.com/Sergio744/Neon-Rift.git
cd Neon-Rift
npm install
npm run dev   # http://localhost:3030
npm test      # suite de tests automatisée
